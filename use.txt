1. MAIN COMMANDS FIRST (RUN THESE IN TERMINAL FROM PROJECT ROOT)
--------------------------------------------------------------------------------
Open PowerShell or VS Code Terminal inside: `e:\Capstone\placement-react-web`

  1) Install dependencies (run once, or after pulling package.json updates):
     npm install

  2) Start the app locally (MAIN COMMAND for daily development & demo):
     npm run dev
     -> Opens local server (typically http://localhost:5173)

  3) Check code quality / linting (verifies React rules & zero unused imports):
     npm run lint

  4) Build production bundle (verifies app compiles cleanly into /dist):
     npm run build

  5) Preview the compiled production build locally:
     npm run preview

--------------------------------------------------------------------------------
Right now, Phase 1 and Phase 2 frontend screens work 100% standalone using built-in
mock adapters (`useAuthMock.js` and `useAssessmentWorkspace.js`).

  Step 1: Run `npm install` (if `node_modules` is missing), then `npm run dev`.
  Step 2: Open the URL printed in your terminal (usually http://localhost:5173).
  Step 3: Test Phase 1 (Authentication):
          - Student Portal tab -> click "Demo Auto-Fill ID" (or type an ID)
            -> Request OTP -> enter `123456` (or click Demo Auto-Fill) -> Verify.

            `Teacher / Faculty`, `College Admin`, `Super Admin`).
  Step 4: Test Phase 2 (Assessment Engine):
          - Make sure active role is `Student`.
          - Click "Launch Assessment Engine" (or "Open Phase 2 Exam UI").
          - Test all 5 questions:
            * Q1 & Q2 (MCQs): Click options or press keys `1`–`4`; try "Mark for Review".
            * Q3 (Simulation Coding): Drag the center split divider, switch languages
              (Python/Node.js/C++/Java), edit the `TODO` function, and click
              "Run Sample Cases" to see the simulated QStash -> Sandbox console.
            * Q4 (SQL Task): Expand PostgreSQL schema tables, edit SQL query with
              `GROUP BY` + `HAVING`, and click "Run Query".
            * Q5 (UI Task): Toggle `Code | Split | Preview` modes, update classes
              (`bg-slate-900`, `emerald`, `role="progressbar"`, `indigo`), and
              click "Verify UI".
          - Click "Questions" to open the Question Navigator drawer, then click
            "Submit Exam" to test the confirmation dialog and QStash receipt screen.
